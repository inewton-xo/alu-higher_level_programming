# Python - import & modules

Exercises on importing functions and variables, using command-line
arguments, and keeping code from running when a file is imported.
All files are executable and start with `#!/usr/bin/python3`.

| File | Description |
|---|---|
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports add, sub, mul, div from `calculator_1.py` and prints each result |
| `2-args.py` | Prints the number of arguments and each argument with its position |
| `3-infinite_add.py` | Prints the sum of all arguments, including very large numbers |
| `4-hidden_discovery.py` | Prints the names defined by the compiled module `hidden_4.pyc` |
| `5-variable_load.py` | Imports the variable `a` from `variable_load_5.py` and prints it |

## Requirements

- Python 3 (`4-hidden_discovery.py` needs Python 3.8 to load `hidden_4.pyc`)
- Style checked with `pycodestyle`
- Code does not run when the file is imported
