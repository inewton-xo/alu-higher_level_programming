# python-exceptions

Python exercises on handling and raising exceptions.

| File | Description |
| ---- | ----------- |
| 0-safe_print_list.py | Prints x elements of a list safely |
| 1-safe_print_integer.py | Prints an integer safely |
| 2-safe_print_list_integers.py | Prints and counts the integers of a list |
| 3-safe_print_division.py | Divides two integers with a debug print |
| 4-list_division.py | Divides two lists element by element |
| 5-raise_exception.py | Raises a type exception |
| 6-raise_exception_msg.py | Raises a name exception with a message |
