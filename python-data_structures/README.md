# python-data_structures

Python exercises on lists, tuples and basic data structures.

| File | Description |
| ---- | ----------- |
| 0-print_list_integer.py | Prints all integers of a list |
| 1-element_at.py | Safely retrieves an element at an index |
| 2-replace_in_list.py | Replaces an element in a list in place |
| 3-print_reversed_list_integer.py | Prints integers of a list in reverse |
| 4-new_in_list.py | Replaces an element in a copy of a list |
| 5-no_c.py | Removes every `c` and `C` from a string |
| 6-print_matrix_integer.py | Prints a matrix of integers |
| 7-add_tuple.py | Adds two tuples element-wise |
| 8-multiple_returns.py | Returns the length and first character of a string |
| 9-max_integer.py | Finds the biggest integer in a list |
| 10-divisible_by_2.py | Flags multiples of 2 in a list |
| 11-delete_at.py | Deletes an item at a given index |
| 12-switch.py | Swaps two variables |
