# Python - Hello, World

Introductory exercises on running Python, printing, f-strings, and string
slicing.

| File | Description |
|---|---|
| `0-run` | Bash script that runs the Python file named in `$PYFILE` |
| `1-run_inline` | Bash script that runs the Python code in `$PYCODE` |
| `2-print.py` | Prints a fixed sentence |
| `3-print_number.py` | Prints an integer followed by `Battery street` |
| `4-print_float.py` | Prints a float with 2 digits of precision |
| `5-print_string.py` | Prints a string 3 times, then its first 9 characters |
| `6-concat.py` | Concatenates two strings into a sentence |
| `7-edges.py` | Prints the first 3, last 2, and middle letters of a word |
| `8-concat_edges.py` | Builds a sentence using only slicing |
| `9-easter_egg.py` | Prints "The Zen of Python" |
