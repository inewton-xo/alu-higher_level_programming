# python-more_classes

More on classes in Python: properties, string representation, `__repr__`
with `eval()`, `__del__`, class attributes, static methods and class methods.

## Files

| File | Description |
| --- | --- |
| `0-rectangle.py` | Empty class `Rectangle` |
| `1-rectangle.py` | `Rectangle` with validated `width` and `height` properties |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__` to draw the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` usable with `eval()` |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the `number_of_instances` class attribute |
| `7-rectangle.py` | Adds the `print_symbol` class attribute |
| `8-rectangle.py` | Adds the static method `bigger_or_equal()` |
| `9-rectangle.py` | Adds the class method `square()` |
