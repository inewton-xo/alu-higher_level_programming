# Python - if/else, loops, functions

Exercises on conditional statements, loops, and writing functions in Python 3.
All files are executable and start with `#!/usr/bin/python3`.

| File | Description |
|---|---|
| `0-positive_or_negative.py` | Prints whether a random number is positive, zero, or negative |
| `1-last_digit.py` | Prints the last digit of a random number and compares it to 5 |
| `2-print_alphabet.py` | Prints the lowercase alphabet on one line |
| `3-print_alphabt.py` | Prints the lowercase alphabet except `q` and `e` |
| `4-print_hexa.py` | Prints numbers 0 to 98 in decimal and hexadecimal |
| `5-print_comb2.py` | Prints numbers 00 to 99 separated by `, ` |
| `6-print_comb3.py` | Prints all combinations of two different digits |
| `7-islower.py` | `islower(c)`: checks for a lowercase character |
| `8-uppercase.py` | `uppercase(str)`: prints a string in uppercase |
| `9-print_last_digit.py` | `print_last_digit(number)`: prints and returns the last digit |
| `10-add.py` | `add(a, b)`: returns the sum of two integers |
| `11-pow.py` | `pow(a, b)`: returns a to the power of b |
| `12-fizzbuzz.py` | `fizzbuzz()`: prints 1 to 100 with Fizz, Buzz, and FizzBuzz |

## Requirements

- Python 3, style checked with `pycodestyle`
- No modules imported, except `random` where the starter code already does so
