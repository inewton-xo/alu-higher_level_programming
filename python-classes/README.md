# python-classes

Introduction to classes in Python: defining a class, private instance
attributes, properties (getters/setters), validation, and printing.

## Files

| File | Description |
| --- | --- |
| `0-square.py` | Empty class `Square` |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | Adds `size` type and value validation |
| `3-square.py` | Adds the `area()` method |
| `4-square.py` | Adds a `size` property getter and setter |
| `5-square.py` | Adds `my_print()` to print the square with `#` |
| `6-square.py` | Adds a validated `position` property used by `my_print()` |
